:===============================================================================
: SARDINE DYNAMIC ENERGY BUDGET (DEB) PARAMETERS
: Parameters are grouped into the two namelists read by debmodel.F90.
:===============================================================================
:
:------------------------------------------------------------------------------
: deb_para          SPECIES-SPECIFIC DEB AND REPRODUCTION PARAMETERS
:------------------------------------------------------------------------------
:
: pAm     : maximum surface-area-specific assimilation rate (J cm-2 d-1)
: pMi     : volume-specific somatic maintenance cost (J cm-3 d-1)
: EG      : volume-specific cost of structural growth (J cm-3)
: vc      : energy conductance (cm d-1)
: kap     : fraction of mobilized energy allocated to somatic maintenance
:           and growth (dimensionless)
: Kx      : assimilation efficiency (dimensionless); currently stored for each
:           particle but not used by the active DEB equations
: Hp      : maturity threshold at puberty (J; Nisbet, 2012)
: TA      : Arrhenius temperature controlling metabolic-rate correction (K)
: K       : half-saturation constant for food limitation (mg C m-3)
: shapeb  : shape coefficient at birth, after correction for larval shrinkage
:           (dimensionless structural length / physical length)
: lfactor : minimum larval acceleration correction applied to assimilation
:           (dimensionless)
: E0      : energy content of one egg (J egg-1)
: Rfbatch : relative batch fecundity (eggs g-1 body mass)
: SF      : reference batch-spawning frequency (d-1)
:--------------------------------------------------------------------------------
:
 &deb_para
    pAm     = 987.0
    pMi     = 103.0
    EG      = 2803.0
    vc      = 0.420
    kap     = 0.53
    Kx      = 0.80 
    Hp      = 49912.0
    TA      = 12989.0
    K       = 9.99
    shapeb  = 0.070
    lfactor = 0.180
    E0      = 1.110
    Rfbatch = 400.0
    SF      = 0.0840/
:
:------------------------------------------------------------------------------
: deb_fixed_param  SHARED AND INITIALIZATION PARAMETERS
:------------------------------------------------------------------------------
: kj      : maturity-maintenance rate coefficient (d-1); currently read but
:           not used by the active DEB equations
: Hb      : maturity threshold at birth/first feeding (J; Nisbet, 2012)
: Hj      : maturity threshold at metamorphosis (J)
: T1      : reference temperature for metabolic rates (K)
: TAL     : low-temperature Arrhenius parameter (K); currently read but unused
: TL      : lower boundary of the tolerance range (K); currently read but unused
: shape   : post-larval shape coefficient (dimensionless structural length /
:           physical length)
: d_V     : structural dry-mass density (g cm-3)
: rho_V   : energy density of structural dry mass (J g-1)
: rho_E   : energy density of reserve dry mass (J g-1)
: rho_R   : energy density of reproduction-buffer dry mass (J g-1)
: rho_Gam : energy density of gamete dry mass (J g-1)
: Kr      : fraction of reproduction-buffer energy transferred to gametes
:           (dimensionless)
: Sizeb   : physical length at birth/first feeding (cm)
: Lj      : physical length at the end of larval acceleration (cm)
: TR      : spawning-onset temperature (K); currently read but unused
: E_i     : initial reserve energy assigned to an egg (J)
: R_i     : initial reproduction-buffer energy assigned to an egg (J)
:--------------------------------------------------------------------------------
:    
 &deb_fixed_param
    kj      = 0.048
    Hb      = 0.09
    Hj      = 30.0
    T1      = 293.0
    TAL     = 30000.0
    TL      = 281.0
    shape   = 0.2
    d_V     = 0.106
    rho_V   = 20100.0
    rho_E   = 31332.0
    rho_R   = 24937.0
    rho_Gam = 23880.0
    Kr      = 0.95
    Sizeb   = 0.40
    Lj      = 4.0
    TR      = 286.0
    E_i     = 0.110
    R_i     = 0.0/
