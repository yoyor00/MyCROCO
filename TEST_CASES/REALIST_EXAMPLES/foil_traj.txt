:=============================================================================
:                  LAGRANGIAN PARTICLE-TRACKING CONFIGURATION (FOIL)
:=============================================================================
:
:-----------------------------------------------------------------------------
: namtraj          GENERAL INPUT SETTINGS
:-----------------------------------------------------------------------------
:
: file_trajec : path to the patch initialization file containing the initial
:               particle positions, trajectory dates, movement settings, and
:               output filenames. Each patch declares its own type (1=circle,
:               2=rectangle, 3=NetCDF positions) as the first field of its
:               block. When FOIL is active, every patch (of any type) also
:               carries the FOIL/DEB initial conditions (species, stage,
:               size, ...) as trailing fields, e.g. foil_ibm_patch.dat.
: dir_pathout : optional base directory for trajectory output, and restart files
:               used by FOIL configuration
: dtsave_traj : time step of LAGRANGIAN outputs
:
:-----------------------------------------------------------------------------
:
 &namtraj
 	file_trajec = "TEST_CASES/REALIST_EXAMPLES/foil_ibm_patch.dat"
	dir_pathout = "./"
	dtsave_traj = 1.d0 /
:
:-----------------------------------------------------------------------------
: namrestart     RESTART SETTINGS
:-----------------------------------------------------------------------------
:
: lagrangian_restart : if true, restore Lagrangian particles from the last time step
:                    stored in the particle restart files, including DEB-IBM
:                    properties when FOIL is enabled
:
:-----------------------------------------------------------------------------
:
 &namrestart
      lagrangian_restart = .false. /
:
:-----------------------------------------------------------------------------
: namreproducibility   RANDOM-NUMBER REPRODUCIBILITY SETTINGS
:-----------------------------------------------------------------------------
:
: reproducibility : if .TRUE., each particle receives the same random values 
:                   at a given time step, regardless of the MPI decomposition.
:                   This applies to Lagrangian random walks and, when FOIL is 
:                   enabled, to individual variability. Results are therefore 
:                   reproducible across MPI decompositions. If .FALSE., the 
:                   intrinsic randomstream is used instead (faster, but 
:                   decomposition-dependent)
:
:-----------------------------------------------------------------------------
:
 &namreproducibility
      reproducibility = .TRUE. /
:
:-----------------------------------------------------------------------------
: namtrajadiff        PARTICLE ADVECTION/DIFFUSION SETTINGS
:-----------------------------------------------------------------------------
:
: hadv : if FALSE, particles will not be transported in the horizontal
: 			direction, neither advection nor diffusion.
:			Usefull for some configuration (ex : 3D-1DV, but also
:			for some biological stages of the IBM)
: dtz   : time step (s) used by the vertical random-walk subloop
:         A value of a few seconds helps prevent particle accumulation in
:         low-diffusivity regions and near boundaries. See Ross and Sharples
:         (2004, Limnology and Oceanography) for a sensitivity analysis.
: hdiff : horizontal diffusion coefficient (m2 s-1); set to 0 to disable
:         horizontal diffusion, when traj3d = .TRUE.
: transport_min_depth : minimum water depth (m) allowed for a new position
:         produced by horizontal particle advection/diffusion. The movement is
:         rejected below this depth. Set to 0 to disable this restriction.
:-----------------------------------------------------------------------------
:
 &namtrajadiff
      hadv = .TRUE.
	 dtz  = 3
      hdiff = 5.0
      transport_min_depth = 2.0 /
