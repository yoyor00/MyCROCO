:=============================================================================
:                  LAGRANGIAN PARTICLE-TRACKING CONFIGURATION
:=============================================================================
:
:-----------------------------------------------------------------------------
: namtraj          GENERAL INPUT SETTINGS
:-----------------------------------------------------------------------------
:
: file_trajec : path to the patch initialization file containing the initial
:               particle positions, trajectory dates, movement settings, and
:               output filenames
: dir_pathout : optional base directory for trajectory output, and restart files
:               used by FOIL configuration
: itypepatch  : method used to define the initial patch positions:
:               1 = circular patches
:               2 = rectangular patches
:               3 = positions read from a NetCDF file
:               This value must match the format of file_trajec.
:
:-----------------------------------------------------------------------------
:
 &namtraj
 	file_trajec = './'traject3d_type1circ.dat
	dir_pathout = './output/'
	itypepatch = 1 /
:
:-----------------------------------------------------------------------------
: namtrajdiff        PARTICLE DIFFUSION SETTINGS
:-----------------------------------------------------------------------------
:
: dtz   : time step (s) used by the vertical random-walk subloop
:         A value of a few seconds helps prevent particle accumulation in
:         low-diffusivity regions and near boundaries. See Ross and Sharples
:         (2004, Limnology and Oceanography) for a sensitivity analysis.
: hdiff : horizontal diffusion coefficient (m2 s-1); set to 0 to disable
:         horizontal diffusion
:
:-----------------------------------------------------------------------------
:
 &namtrajdiff
    dtz  = 3
    hdiff = 5.0 /
